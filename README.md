# English-football-performance-analytics
Project Overview

This project analyzes 8,882 English football matches across four divisions and 100 clubs between 2020 and 2025 using MySQL, Python, and Power BI.

The objective was to identify team performance trends, scoring patterns, home advantage, league competitiveness, and season-level insights through SQL analytics, exploratory data analysis, and dashboard visualization.
Tools & Technologies
MySQL 8
Python (Pandas, Matplotlib, Seaborn)
Power BI
SQL Window Functions
CTEs
Aggregations
Data Cleaning & EDA

Dataset
8,882 football matches
100 clubs
Four English divisions
Match results from 2020–2025

## Business Questions Answered
- Which teams performed best overall?
- How significant is home advantage?
- Which clubs score the most goals?
- Which seasons were the highest scoring?
- Which divisions are most competitive?
- How do home and away performances compare?
- Which teams have the strongest goal difference?

  ### Key Insights
🏆 Home Advantage Exists
-Home teams won 42.9% of matches.
-Away teams won 31.9%.
-Home advantage created an 11% performance gap.
⚽ Scoring Trends
-Total goals scored: 23,336
-Average goals per match: 2.6
-Nearly 47% of matches ended with 2–3 goals.
